# Версия 364 — силовой каркас на плане

Верхний слой «Силовой каркас» показывает существующие вертикальные детали стен и перегородок, проёмы и проектные стойки. Выбор стены открывает общую развёртку с фронтоном. Можно добавлять и перемещать обычные окна и двери, перемещать вертикальные стойки, добавлять пакеты из 1–3 досок 50×150. Конструктор витража открывается с выбранными стеной и этажом. Его геометрия и связи с опорами крыши сохраняют прежний механизм применения.

Пакеты включены в существующие проектные опоры, смету и раскрой по отдельным доскам. Для стойки можно выбрать верхний прогон/балку; сохраняются проверки опирания. Основание с явным проектным обозначением создаёт отдельную опорную ссылку. Несущая способность и крепёж автоматически не назначаются. Перемещение соединителя SIP сохраняется по исходному ключу; недопустимое смещение за стену или в проём отклоняется. Изменение паза SIP требует рабочего узла, без него выводится предупреждение. Автоматическая сетка панелей при таком смещении не перестраивается.

Добавлено ручное сечение стропил 50×100. Существующие исходные значения и автоматический выбор сохранены. При одинаковой закупаемой длине объём составляет 2/3 от 50×150; используется действующая позиция прайса 50×100. Например, при 306 м доски объём 2,295 → 1,530 м³. Цена позиции не изменена. Стойка высотой 2500 мм из двух досок 50×150 добавляет 0,0375 м³, из трёх — 0,05625 м³, по существующей цене; работа и крепёж требуют проектного назначения.

Исправлены исчезновение окон при блокировке раскроя стены и потеря привязки фронтона после выреза витража. Предупреждения раскроя сохраняются. Меню слоёв 3D вынесено в портал с ограничением высоты по экрану, вертикальной прокруткой и touch-action: pan-y.

Проверки: npm ci; npm test — 1355/1355; npm run build. Целевые регрессии: сечение/каталог/объём стропил; устойчивое смещение и импорт; пакеты в опорах, 3D, раскрое и смете; окна при блокировке и привязка фронтона. В браузере проверены добавление окна и пакета, перемещение через параметры, Del, отмена/повтор, сохранение и повторное открытие файла. Ширины 820 и 390 px без переполнения редактора; меню из 34 пунктов прокручено до конца. Проверка на физическом iPad/Safari не выполнена.

Публикация: статические файлы калькулятора на Timeweb; API, CRM, базы данных, почта и проекты сервера не изменяются.
