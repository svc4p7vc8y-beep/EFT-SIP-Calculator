# Релиз 136

## Изменения

- Отключение работ в клиентской смете не исключает раскрой; это действует и в компактном режиме.
- Excel учитывает выбранный состав клиентской сметы.
- План сохраняет данные заказчика и анкету. Импорт шаблона не заменяет номер текущего проекта.
- Новый проект и импорт анкеты из файла получают следующий номер. Локальный счётчик не откатывается после открытия старого проекта; общая база использует серверный счётчик.
- Для новых проектов выбраны равномерная раскладка свай и пакет досок. Старые проекты сохраняют свои настройки, включая прежние значения при отсутствующих полях.
- Настройки состава сметы сгруппированы в адаптивную панель.
- Очередь облачного сохранения привязана к исходному проекту, даже при переключении на другой.
- Service Worker не кеширует API, приватные ответы и ответы с ошибками.

## Проверки

261 автоматический тест: расчёты, 36 сочетаний конструктивных настроек, миграции, перенос плана, экспорт, нумерация и переключение проектов при сохранении.

Прошли установка зависимостей, production-сборка калькулятора и сборка публичного сайта. В локальном Chrome открыты 17 разделов без ошибок JavaScript; проверены сохранение настроек после перезагрузки, отмена, загрузка Excel и последовательное создание проектов. Панель сметы проверена на ширинах 390, 430, 768, 1024 и 1440 px.

Облачная очередь проверена с имитацией API, без изменения клиентских данных на сервере. Реальный многопользовательский вход и почтовая интеграция не входят в подтверждённые результаты этой проверки. Настройка почты отложена по просьбе пользователя.

Цены и нормы расхода не изменены. При отключённых работах итог увеличивается относительно ошибочного поведения на стоимость ранее скрытого раскроя. Общий расчёт материалов не изменяется.
