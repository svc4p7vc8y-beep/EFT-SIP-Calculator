# EFT SIP Calculator v151

Релиз устраняет подтверждённые аудитом разрывы сохранения, синхронизации,
почтового API, мобильной шапки и автоматической публикации.

## Основные изменения

- текущий проект получает контрольную копию перед созданием, импортом или
  открытием другого проекта;
- общие библиотеки регулярно обновляются и сохраняются с проверкой ревизии;
- конфликт библиотек объединяет записи по ID и времени изменения вместо
  молчаливой перезаписи;
- архивирование анкет остаётся только в защищённом admin-действии;
- чтение письма через GET больше не меняет IMAP-состояние; отметка прочтения
  выполняется отдельным CSRF-защищённым запросом;
- добавлено преобразование charset тела письма в UTF-8 и корректное определение
  MIME вложений;
- повторная отметка анкеты не уменьшает счётчик второй раз;
- исправлено отображение итоговой цены на ширине 390–430 px;
- локальный запуск не обращается к командному API без режима `?cloud=1`;
- расширены триггеры публикации и PHP lint всех серверных файлов;
- добавлено ограничение неудачных попыток входа: 8 попыток за 15 минут по IP
  или учётной записи, затем блокировка на 15 минут.

Расчётные формулы, цены, нормы расхода, геометрия проектов и идентификаторы
каталога не изменялись.
