# Версия 366 — общие переключатели слоёв и панели iPad

В верхней строке слоёв плана добавлена галочка «Все»: включить/выключить весь набор. Частичная видимость отмечена промежуточным состоянием. Изменение относится к текущему этажу и является одним действием отмены. Геометрия, цены и ручные количества при переключении не меняются. В меню «Слои 3D» есть отдельная общая галочка; она закреплена над прокручиваемым списком и сохраняет неизвестные настройки видимости будущих слоёв.

На планшетных ширинах 701–1400 px и устройствах с сенсорным указателем слои плана и инструменты масштаба находятся в двух независимых горизонтально прокручиваемых строках. Кнопки увеличены; галочка «Все» остаётся слева. Панели дополнительных инструментов отодвинуты ниже. Ряды 3D-панели, слои инженерии и управление рабочим полем получили горизонтальную прокрутку; вертикальные инструментальные колонки — прокрутку по вертикали. Действуют native overflow и touch-action, без перехвата свайпов рисунком.

Ширина правой колонки ограничивается доступным пространством на планшете. Сохранённая широкая колонка больше не сжимает рабочее поле до нуля после смены ширины. Для сенсорного разделённого вида сохранены три колонки, с ограничением ширины 3D и параметров относительно контейнера. Широкий настольный режим сохраняет прежнее расположение панелей.

Проверки: npm ci; npm test — 1364/1364; npm run build. В браузере проверены общий показ/скрытие слоёв плана и 3D, промежуточное состояние, отмена, прокрутка до последних значков на узком поле, полный экран, отсутствие наложения рядов и дополнительных инструментов, переход 1024 → 820 px с широкой сохранённой колонкой, ширины 390 и 1600 px и отсутствие ошибок в консоли. Физический iPad/Safari недоступен; жест пальцем на устройстве не проверен.

Публикуются только статические файлы калькулятора Timeweb. API, CRM, базы, почта и серверные проекты не меняются.
