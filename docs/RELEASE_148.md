# EFT SIP Calculator — версия 148

## Общее файловое хранилище

- В левой панели добавлен раздел «Файлы».
- Сотрудники могут создавать вложенные папки и загружать несколько файлов.
- Файлы хранятся в общей серверной базе и доступны только после входа сотрудника.
- Вложения всех анкет собраны в отдельной папке «Файлы из анкет» без дублирования данных.
- Постоянная плашка «Файлы из анкеты» удалена с рабочего поля калькулятора.
- Поддерживаются документы, таблицы, презентации, изображения, архивы, JSON, DWG и DXF.
- Ограничения: до 8 МБ на файл, до 20 МБ и до 10 файлов за одну загрузку.

## Вложения в исходящих письмах

- При ответе на письмо можно выбрать до восьми файлов.
- Вложения отправляются через уже подключённый защищённый SMTP-аккаунт `sale@eftsip.ru`.
- Один файл может занимать до 8 МБ, общий размер вложений — до 20 МБ.
- Файлы формируются как стандартное MIME-письмо и не публикуются по открытой ссылке.
