# Резервный калькулятор на GitHub Pages

Адрес: https://svc4p7vc8y-beep.github.io/EFT-SIP-Calculator/reserve/react.html

Workflow Pages сохраняет публичный сайт в корне и добавляет отдельную сборку калькулятора в `reserve/`. Флаг `VITE_EFT_STANDALONE=true` действует только для этой сборки. Основная сборка Beget сохраняет авторизацию и серверный режим.

Резервная версия работает без входа, сохраняет рабочие вкладки на устройстве и поддерживает библиотеку планов, импорт и экспорт `.eft.json`, расчёты и сметы. Изменения не синхронизируются с Beget; проекты, открытые на другом домене или устройстве, автоматически не переносятся. Для переноса нужно скачать файл проекта и импортировать его в основной калькулятор после восстановления сервера. Цены берутся из текущей сборки или импортированного проекта, а не из недоступного общего прайса.

С версии 326 есть раздел **Резервные копии**. В Chrome/Edge на компьютере выберите локальную папку и разрешите запись. В подпапке `EFT-резерв` сохраняются открытые проекты `.eft.json`, планы и структура локальной библиотеки, прайсы. Изменения копируются через 1,5 секунды после остановки редактирования, пока приложение открыто. Перед закрытием можно нажать «Сохранить и сверить сейчас» и дождаться результата. После перезапуска браузер может потребовать повторного разрешения записи.

В основном калькуляторе при активной серверной сессии папка сверяется с сервером раз в минуту. `backup-index` возвращает только список версий; полные проекты, записи библиотеки и прайс запрашиваются только для отсутствующих/повреждённых копий. Сверка выполняет только GET: ничего не удаляет и не восстанавливает на сервере. Новые версии сохраняются отдельными файлами. Каталог состоит из отдельных записей в папке `Каталог`, чтобы одновременные вкладки не затирали общий список.

Резервная сборка не обращается к недоступному Beget. Чтобы использовать там сохранённые проекты, выберите ту же папку и откройте копию через раздел «Резервные копии». Разрешение на папку выдаётся отдельно для каждого сайта. Прайс можно импортировать в разделе «Прайс-лист»; открытые рабочие проекты также содержат собственные таблицы цен. Файлы серверного хранилища (изображения/PDF) отдельно не скачиваются; встроенные данные проекта сохраняются вместе с ним.

Локальная проверка:

```powershell
npm ci
npm test
npm run build:public
$env:VITE_EFT_STANDALONE='true'
npm run build
node scripts/prepare-github-reserve.mjs
```
