# Резервный калькулятор на GitHub Pages

Адрес: https://svc4p7vc8y-beep.github.io/EFT-SIP-Calculator/reserve/react.html

Workflow Pages сохраняет публичный сайт в корне и добавляет отдельную сборку калькулятора в `reserve/`. Флаг `VITE_EFT_STANDALONE=true` действует только для этой сборки. Основная сборка Beget сохраняет авторизацию и серверный режим.

Резервная версия работает без входа, сохраняет рабочие вкладки на устройстве и поддерживает библиотеку планов, импорт и экспорт `.eft.json`, расчёты и сметы. Изменения не синхронизируются с Beget; проекты, открытые на другом домене или устройстве, автоматически не переносятся. Для переноса нужно скачать файл проекта и импортировать его в основной калькулятор после восстановления сервера. Цены берутся из текущей сборки или импортированного проекта, а не из недоступного общего прайса.

Локальная проверка:

```powershell
npm ci
npm test
npm run build:public
$env:VITE_EFT_STANDALONE='true'
npm run build
node scripts/prepare-github-reserve.mjs
```
