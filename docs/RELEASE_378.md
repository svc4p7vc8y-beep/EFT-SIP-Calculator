# Версия 378 — автоматическая ориентировочная цена окон витражного фасада

Причина нулевых строк: applyFacade создаёт связанные изделия с режимом design_unpriced, а смета конфигуратора имела приоритет над обычным площадным расчётом проёма. Эскиз без цены становился строкой с pricePending и ценой0, даже когда в проекте были доступные ориентиры.

Один расчёт windowPrice теперь получает действующий прайс проекта. Для корректных окон, связанных с фасадом, без ручной цены/параметрического тарифа автоматически используется совместимый образец расчёта №273803 с пересчётом по фактической площади. У треугольников учитывается именно площадь треугольника, у трапеций — две высоты. Источник содержит номер образца, исходную сумму, площадь и предупреждение о неизвестной дате исходной цены.

Если совместимого конструктива нет, применяется существующая ставка MAT-241 (либо MAT-240 в старом проекте без MAT-241), только в единицах м². При стандартном прайсе это9722,22 ₽/м² ×2 — прежний коэффициент панорамного остекления. Ставки и коэффициенты не изменены. Пример: глухая прямоугольная панель2×2м, ранее строка без цены/0 ₽, теперь ориентировочно77777,76 ₽. Для треугольника2000×1732мм площадь1,732м²; источник №12 (8498,25 ₽ за0,433м²) даёт33993 ₽.

Цена появляется сразу после применения фасада и при открытии старого проекта, без изменения его сохранённой геометрии/общего прайса. Смета, конфигуратор, ведомость, печать окон/PDF и Excel используют общий расчёт. Автоматические бюджетные строки явно отмечаются «Ориентировочно», источник доступен по подсказке и в расчётной ведомости. Повторного учёта одного окна на стене и фронтоне нет. Исключение проёма из сметы, ручные цены, ручные правки строк и параметрические тарифы имеют приоритет. Невалидные изделия и отсутствующие/нулевые ставки не получают выдуманную цену. Монтаж и дополнительная комплектация сохраняют прежние правила. Москитные сетки не добавляются: пользователь уточнил, что имелось в виду включение в смету.

На контрольном сохранённом проекте семь изделий: ранее оценивалось одно на20867,39 ₽, шесть были без цены. Теперь все семь имеют оценку, сумма окон176666,92 ₽ (увеличение155799,53 ₽). Это пример проверки, не цена пользовательского заказа. Геометрия и площадь10,613523 м² не менялись.

Проверка: npm ci; npm test —1419/1419; производственная сборка. Новые регрессии: ориентир по текущему прайсу и его изменение, истинная площадь треугольника/совместимый источник, защита ручных цен и нулевых ставок, применение/импорт фасада, однократное включение каждого изделия, отсутствие мутаций и сохранение исключений. Браузер: старый файл открывается без перепроектирования, семь положительных строк в основной смете, общая стоимость совпадает с ведомостью окон, пометки «Ориентировочно» и источники видны, ошибок приложения в консоли нет.
