# Инженерные схемы — версия 350

По согласованному заданию EFT добавлены три связанных вида: план, стены комнаты, схема обвязки. Используются существующие placement.items и placement.networks; копии оборудования для схемы не создаются. Открыть: «Мебель и инженерия» → Водоснабжение / Отопление / Канализация → «Схема обвязки».

## Автоматическая заготовка

Это редактируемая компоновка, а не гидравлический расчёт или монтажная норма. Вода: ввод, отключающий кран, фильтр; нагреватель только при наличии неподключённых потребителей ГВС. Канализация: выпуск из дома и ревизия, подключение существующих потребителей. На верхнем этаже вместо уличного ввода/выпуска используются стояки; межэтажные подключения уточняются проектировщиком. Отопление: источник, сервисные соединения, отключение, фильтр, подпитка и слив; внешние насос, бак и группа безопасности исключаются настройками встроенного оборудования. Тройниковая и коллекторная разводки имеют отдельные линии подачи и обратки.

Высоты временные и помечены heightKnown=false. Диаметры, материал, уклон, шаг креплений не назначаются за пользователя. Для схемы с пустым водоснабжением добавляется 3 элемента, с пустой канализацией — 2. Старые проекты не заполняются автоматически; дополнение запускается явной кнопкой и отменяется общей историей. Повторный запуск сохраняет существующие ID, ручные линии и настройки. Автоматика не переключает тип разводки уже готовой сети: переделка существующей схемы выполняется вручную.

## Координаты и ведомость

`item.networkDiagram={x,y}` хранит только координаты на принципиальной схеме; они не участвуют в длинах труб. Физическое положение определяется x/y/height/wallRef. Движение на стене меняет реальные трассы; связанный прибор переносит свои выводы по трём координатам. `schemeRole` обозначает узел шаблона; `schemeOwnerId` связывает отдельные части с источником тепла для устранения задвоений комплекта.

Элементы, трубы, повороты, тройники и крепления входят в инженерную ведомость. Дополнительные количества комплекта котла учитываются за вычетом уже нарисованных соответствующих деталей; более высокие ручные количества сохраняются. Прежние цены и нормы не заменялись, новые цены не придуманы. Источник количества фитингов — топология трасс и явно расставленные узлы; шаг креплений берётся только из ввода пользователя. Канализационные фитинги, ранее не выводившиеся автоматически, теперь выводятся по топологии, без автоматического выбора угла/артикула. Ведомость инженерного редактора не заменяет проверку спецификации и подбор оборудования по проекту.

Печать/PDF использует те же граф и координаты. Схемы появляются в выборе листов «Планы для рабочих / PDF» и могут быть отключены отдельно.

## Проверка

Регрессионные сценарии: повторное построение, старый JSON и миграция, сохранение ручных трасс, разные среды/этажи, встроенное оборудование, существующие выводы котла, независимость длины трубы от координат схемы, перенос выводов, задвоение комплекта, непрерывный уклон канализации, стояк верхнего этажа и печатные листы. Проверка UI: ручное добавление водорозетки, соединение ХВС, изменение высоты, смена системы, базовая канализация/отопление, предварительный просмотр печати, телефон/планшет.
