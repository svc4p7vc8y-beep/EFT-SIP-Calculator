# Версия 380 — материал каркаса витражных фасадов

По поручению пользователя автоматический материал стоек, усилений, горизонтальных и наклонных балок витражного фасада наследует тип основного каркаса SIP: connectorType и wallThickness. Поддержаны клеёный пакет, комплект досок, термобрус и обычный брус. Цены прайса и геометрия не меняются. Явный материал фасада и отдельных элементов сохраняется.

Ранее при пустом catalogId подбиралась доска по сечению packageProfile. Теперь используется соответствующая позиция материала основного каркаса. Для ставки за м³ количество равно физическому объёму. Для ставки за погонный метр количество = физический объём / площадь исходного сечения. Это эквивалент количества материала для сметы; проектное сечение усилителя и рабочие узлы сохраняются. Производственный элемент наследуемого готового пакета учитывается один раз, без повторного умножения цены на число досок. Ручной вариант отдельных досок продолжает раскраиваться отдельно. Доставка использует физический объём, а не эквивалентную длину с увеличенным сечением.

Пример: стойка 150×150×3000 мм, 0,0675 м³. Старый подбор MAT-023 (доска 50×150, 26 400 ₽/м³) давал 1782 ₽. При основном каркасе MAT-187 (клеёный пакет 95×145, 841 ₽/м.п.) количество 4,900182 эквивалентных м.п., стоимость около 4121,05 ₽. Изменение стоимости около +2339,05 ₽; ставки каталога и физический объём не меняются. Пример не является пересчётом заказа пользователя.

Пересчёт выполняется при расчёте без переписывания координат старых проектов. Изменение типа каркаса дома автоматически обновляет материал фасада. При отсутствии нужной позиции цена остаётся явно незаполненной. В параметрах фасада и выбранного элемента показан источник материала. Сохранён ручной выбор материала.

Проверка: npm ci, полный npm test — 1430/1430, npm run build; отдельные регрессии для четырёх типов материала, разных толщин, отсутствующих цен, ручных переопределений, импорта, единиц измерения, доставки и отсутствия двойного учёта. Визуальная проверка светлой темы и планшетной/мобильной ширины выполняется на тестовой копии проекта. Физический iPad не использовался. Публикуется только статическая сборка.
