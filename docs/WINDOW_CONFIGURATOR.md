# Конфигуратор окон EFT

Экран «Окна / двери» показывает библиотеку 12 изделий из расчёта № 273803 и связывает выбранное изделие с `opening.id` на плане. Данные изделия сохраняются в `windowProducts[]` проекта. Габарит изделия указан в миллиметрах, геометрический проём SIP остаётся в метрах в существующем плане; `roughOpening` и четыре `installationGaps` хранятся отдельно. Ни один зазор не подставляется автоматически.

Форма и открывание выбираются независимо. Прямоугольные изделия делятся на секции по ширине или высоте; секции можно задавать долями либо точным размером, с проверкой суммы. Пользовательские шаблоны сохраняются в `windowPresets[]`; повторное использование создаёт новое изделие с новым ID.

## Источник и точность

`src/react/data/window-reference-273803.json` содержит 12 исторических позиций. Исходный PDF остаётся вне репозитория. Точная сумма цен — 131 676,94 ₽; округление общей суммы даёт 131 677 ₽. Сумма напечатанных в PDF целых цен по строкам — 131 676 ₽. Геометрическая площадь составляет 15,0144 м², сумма округлённых напечатанных площадей — 15,00 м².

Историческая цена применяется только к изделию, совпадающему с соответствующим образцом по форме, размерам, секциям, фурнитуре, профилю, стеклопакету и комплектации. Для изменённого изделия с исходной системой BRUSBOX AERO 60, белым профилем и стеклопакетом 32 мм, площадью 0,36–3,60 м² показывается предварительный ориентир `4983.868694574176 + 4786.709802929846 × площадь, м²`. Эта регрессия не является заводским тарифом. Цена для другой системы, неизвестной комплектации или площади вне диапазона не формируется; пользователь может явно ввести проектную цену и её источник.

Параметрический режим принимает импортируемые JSON-тарифы `windowTariffs[]`. У записи обязательны `id`, `supplierId`, `currency: "RUB"`, `source`, `validFrom`, `validTo`, конкретные `profile` и `glazing`, а также `rates` (`baseRub`, `profileRubPerMeter`, `glassRubPerM2`, `impostRubPerMeter`, `hardwareRubByMode`, `shapeSurchargeRubByShape`). Для изделия нужны введённые по поставщику `productionMeasures`: `profileLinearMeters`, `glassAreaM2`, `impostMeters`. При отсутствующей ставке, несовпадении системы или стеклопакета либо истёкшем периоде цена остаётся неподтверждённой. Эталонный расчёт № 273803 не создаёт такие ставки автоматически.

## Смета и экспорт

Привязанное изделие заменяет типовую строку окна и её стандартные строки монтажа/расходников. Материал окна учитывается один раз по ID изделия. Дополнительная комплектация и работы появляются только при включении, указании тарифа и источника. Изделие, связанное с удалённым проёмом, не включается в смету; его данные остаются в проекте для ручного переподключения.

Excel содержит лист «Окна» с габаритами, точными ценами и источником; основной лист сметы также показывает источник каждой строки. Кнопка «Схемы / PDF» создаёт отдельный печатный документ с SVG-схемами и ведомостью для сохранения браузером в PDF. Эти схемы предназначены для согласования, не для производства. Для раскроя, стеклопакетов и подтверждённой параметрической цены нужны таблицы систем профилей, фурнитуры и тарифы изготовителя с датами действия.
